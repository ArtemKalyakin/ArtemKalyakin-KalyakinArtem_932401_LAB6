 Что сделал

Инициализировал проект через npm init и установил express. Написал server.js — сервер на Express, который отдаёт статику и запускается на порту 4000.
Сделал маршруты: GET / (калькулятор), GET /about (о себе), GET /api/status (JSON со статусом сервера) и GET /api/calc — сам калькулятор. В /api/calc принимаю query-параметры a, b и op, проверяю, что a и b — числа, что op из списка + - * /, и что нет деления на ноль. Если что-то не так — возвращаю 400 с текстом ошибки. Если всё ок — { result, expression, error: null }. Ещё сделал вариант через path-параметры: /api/calc/%2B/5/10.
На клиенте сделал форму с двумя полями, выбором операции и кнопкой. Скрипт отправляет запрос на /api/calc и показывает результат или ошибку. Если сервер недоступен, считает локально — чтобы страница работала офлайн.
Для PWA добавил manifest.json с иконкой и подключил его в HTML. Написал sw.js — Service Worker кеширует статику при установке, чистит старые кеши при активации, отдаёт файлы из кеша, а запросы к /api/ всегда пускает в сеть. Зарегистрировал его в script.js.
Вёрстка адаптивная.
